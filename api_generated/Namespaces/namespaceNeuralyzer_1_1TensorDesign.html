function createTensorColumnViews

std::size_t createTensorColumnViews(
    DataManager & dm,
    std::string const & tensor_key,
    std::string const & prefix,
    std::vector< int > const & columns
)

Create AnalogTimeSeries column views from a TensorData in DataManager.

Parameters:

  • dm DataManager containing the tensor
  • tensor_key DataManager key of the source TensorData
  • prefix Prefix for generated AnalogTimeSeries keys
  • columns 0-based column indices to extract (empty = all columns)

Return: Number of views successfully created

Precondition:

  • dm must contain a TensorData at tensor_key
  • The TensorData must be 2D
  • All column indices must be in [0, numColumns())

For each selected column (or all columns if columns is empty), creates a zero-copy AnalogTimeSeries view backed by TensorColumnAnalogStorage and inserts it into the DataManager under “{prefix}/{column_name}”.

function discoverAnalogKeyGroups

std::vector< AnalogKeyGroup > discoverAnalogKeyGroups(
    DataManager & dm
)

Discover groups of AnalogTimeSeries keys sharing a common prefix.

Parameters:

  • dm DataManager to scan for AnalogTimeSeries keys

Return: Vector of key groups, sorted by prefix

Scans all AnalogTimeSeries keys in the DataManager, extracts the prefix before the last ’_’ character, and groups keys by that prefix. Only groups with 2 or more keys are returned.

function populateTensorFromAnalogKeys

bool populateTensorFromAnalogKeys(
    DataManager & dm,
    std::string const & tensor_key,
    std::vector< std::string > const & analog_keys
)

Populate an existing TensorData from AnalogTimeSeries channels.

Parameters:

  • dm DataManager containing the tensor and analog data
  • tensor_key Key of the TensorData to populate
  • analog_keys Ordered list of AnalogTimeSeries keys to pack as columns

Return: true if the tensor was successfully populated

Precondition:

  • dm must contain a TensorData at tensor_key
  • All analog_keys must exist and contain AnalogTimeSeries
  • All channels must share the same TimeFrame and sample count

Gathers the specified AnalogTimeSeries channels, packs them into a 2D TensorData via analogToTensor(), and replaces the data at tensor_key. The TimeKey is inherited from the first analog channel.

function resolveOutputTimeKey

std::optional< TimeKey > resolveOutputTimeKey(
    DataManager & dm,
    TensorDesignSpec const & spec
)

Resolve the TimeKey under which a designed tensor should be registered.

Parameters:

  • dm DataManager containing row source and timeframe registrations
  • spec Design specification

Return: Resolved TimeKey, or nullopt when no valid timeframe exists

Uses an explicit non-default spec.output_time_key when present and valid, otherwise the row source’s TimeKey, then "time" or "default" if registered.
