GatherResult Baseline Test Inventory

Purpose

This document records the Phase 0 baseline for the GatherResult / DigitalIntervalSeries migration. It inventories existing test coverage, lists gaps filled by Phase 0 characterization tests, documents the behavioral contract that later phases must preserve, and provides verification commands.

See also:

  • digital_interval_series_migration_design.qmd — target architecture
  • digital_interval_series_migration_plan.qmd — phased implementation plan

Verification Commands

Use the my-clang-release preset:

# List relevant tests
ctest --preset my-clang-release -N | rg -i "gather|alignment|interval_reduction|plot_alignment|tensor_design|tensor_column|multistep|phase1_3_4"

# Run Phase 0 characterization tests only
ctest --preset my-clang-release --output-on-failure -R "\[migration\]\[phase0\]" > test_log.txt 2>&1

# Run full GatherResult / plot-alignment / interval-reduction / tensor builder suite
ctest --preset my-clang-release --output-on-failure -R "GatherResult|PlotAlignmentGather|interval_reduction|tensor_design|tensor_column|multistep|phase1_3_4" > test_log.txt 2>&1

Baseline Behavior Contract

Original data flow before migration:

Note

Phase 6 has removed the adapter API. The diagram and bullets below remain the historical Phase 0 baseline contract that the migration was designed to preserve or intentionally replace.

flowchart LR
    alignData["DigitalEventSeries or DigitalIntervalSeries"]
    adapters["EventExpanderAdapter / IntervalWithAlignmentAdapter"]
    gather["GatherResult::create"]
    consumers["Plots / IntervalReduction / Export"]

    alignData --> adapters
    adapters --> gather
    gather --> consumers

Event Alignment

  • Each alignment event produces exactly one trial row.
  • Window bounds: [event_time - pre_window, event_time + post_window] in absolute time when the adapter reports nullptr TimeFrame.
  • alignmentTimeAt(i) equals the original event time, not the window start, even for symmetric (centered) windows.
  • Overlapping windows are preserved unless prevent_overlap filters alignment events before gather.

Interval Alignment

  • Start: alignmentTimeAt = interval.start
  • End: alignmentTimeAt = interval.end
  • Center: alignmentTimeAt = (start + end) / 2 (integer division)
  • No-window mode: gathered view spans full interval bounds; adapter exposes interval TimeFrame.
  • Window mode: [align_abs - pre, align_abs + post] in absolute time; adapter reports nullptr TimeFrame.

Overlap Prevention (prevent_overlap)

Implemented in PlotAlignmentGather.hpp, not in GatherResult itself.

  • Greedy keep-first scan over sorted alignment times.
  • Overlap window: [time - window_size/2, time + window_size/2].
  • Keep candidate iff current_start > last_kept_end (touching counts as overlapping).
  • Applied before gather by filtering the alignment series copy.

Reorder

  • reorder(indices) permutes _views only; _intervals and _alignment_times remain in original order.
  • _reorder_indices[display_pos] maps display position to original trial index.
  • originalIndex(i) returns the original trial index for display position i.
  • intervalAtReordered(i) == intervalAt(originalIndex(i)).
  • alignmentTimeAt(i) looks up alignment time via originalIndex(i).
  • isReordered() is true whenever _reorder_indices is non-empty (including identity permutations).

Cross-Timeframe

  • Adapter path (GatherResult::create with IntervalSource): convert adapter indices → absolute time → source indices for view bounds; store absolute alignment time in _alignment_times.
  • Plain interval path (GatherResult::create with DigitalIntervalSeries): no conversion; interval indices used directly as view bounds.
  • IntervalReduction: prepareIntervalsForGather() converts interval TimeFrame → source TimeFrame before gather.
  • Plot helpers (gatherWithEventAlignment, createAlignedGatherResult): delegate to adapter path; cross-timeframe behavior matches low-level adapter tests when source and alignment series carry different TimeFrames.
